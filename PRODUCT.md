# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React + TypeScript + Vite + Tailwind CSS + Framer Motion

## Users

UCEK (University College of Engineering Kariavattom) engineering students (CSE, ECE, IT, and related branches) preparing for campus placements, alumni mentors providing industry guidance, and Placement Officers (TPO) managing campus drive readiness.

## Product Purpose

Provide an all-in-one, AI-powered placement and career readiness portal that equips students with realistic mock assessments, automated ATS resume analysis, interactive HR interview simulation, structured domain learning roadmaps, and direct alumni mentorship matching.

## Positioning

An institution-customized, end-to-end placement ecosystem specifically tailored to UCEK academic workflows—combining real-time AI assessment tools with verified alumni mentorship networks and administrative placement tracking.

## Operating Context

Used by engineering students primarily in desktop/laptop environments for focused practice (mock tests, resume suite, interview simulator) as well as mobile devices for schedule tracking, updates, and mentorship connection.

## Capabilities and Constraints

- **Capabilities**: Role-based authentication switcher (Mentee/Student, Alumni Mentor, Placement Admin), AI Resume Suite with ATS scoring & section feedback, HR Interview Simulator with speech/text prompt evaluation, Domain Roadmaps with progress tracking, Mock Tests with instant scoring, Alumni Mentorship booking, and TPO Admin Analytics.
- **Technical Constraints**: Client-side React 19 web application built with TypeScript, Vite, Tailwind CSS v4, Framer Motion, and Lenis smooth scrolling.

## Brand Commitments

Official UCEK institutional identity context, sleek modern tech aesthetic, vibrant glassmorphism, fluid micro-interactions, dark & light visual options, and professional motivating tone.

## Evidence on Hand

Full incumbent React codebase located at `src/` featuring active pages (`LandingPage.tsx`, `Dashboard.tsx`, `AIResumeSuite.tsx`, `HRInterviewSimulator.tsx`, `DomainRoadmap.tsx`, `Mentorship.tsx`, `MockTests.tsx`, `AdminPanel.tsx`), interactive component library, and mock data suites.

## Product Principles

1. **Immediate Actionable Feedback**: Every practice tool (Resume, HR Interview, Mock Test) provides real-time scoring and clear next steps.
2. **End-to-End Placement Workflow**: Seamlessly guide students from skill gap analysis (Roadmaps) to resume building, interview practice, and mentor validation.
3. **Realistic Campus Recruitment Simulation**: Replicate actual corporate recruitment tests, technical rounds, and HR evaluation dynamics.
4. **Alumni-Student Connection**: Leverage real alumni network expertise to bridge academic training with industry expectations.

## Accessibility & Inclusion

Responsive web design adhering to WCAG contrast guidelines (>=4.5:1), semantic HTML hierarchy, touch-friendly interactives (>=44pt), and role-tailored user interfaces.
